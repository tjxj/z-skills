一行命令，安装任意技能

所有技能托管在同一仓库，用 npx skills 按需安装单个；新会话里 Agent 根据 SKILL.md 的 name / description 自动匹配触发词。

$ npx skills add …

把 <skill> 换成下方任意技能名

$ npx skills add tjxj/z-skills --skill z-grounded-source-qa
01git clone https://github.com/tjxj/z-skills —— 拉取全部源码
02cp -R z-* /path/to/.agent/skills/ —— 一次性安装全部技能
03python3 <skill>/scripts/xxx.py —— 不安装，直接运行脚本

常见问题

$ 必须联网才能用吗？▸
安装时需要网络（npx / git clone）。安装后技能在本地运行，读本地文件、跑本地脚本，不依赖云端服务。
$ 支持哪些 Agent 环境？▸
任何读取 SKILL.md 的环境：Claude Code、Codex，或手动放到本地 .agent/skills/ 目录。匹配依据是每个 SKILL.md 的 name 与 description。
$ 技能会自动触发吗？▸
新会话启动时自动注册；当你的请求命中描述里的触发场景（如「下载B站」「Markdown转PDF」「只根据资料回答」）时，技能自动接管，无需手动调用。
$ 能自己修改或二次开发吗？▸
可以，fork 后直接改 SKILL.md 与脚本。建议保持触发词清晰、流程可执行、输出可验证——这是仓库的维护原则。
$ 遇到付费墙 / 验证码 / 视频号怎么办？▸
采集遇付费墙时会保留受限说明并补公开来源；视频号分享链接由 z-video-downloader 通过在线解析自动获取地址，支持断点续传与字幕封面。

为什么是 Skills

◆ 01

触发词清晰

明确的 name 与 description 声明触发场景，命中即接管，减少反复解释。

◆ 02

流程可执行

能脚本化的都沉淀为 scripts/，优先调用脚本，避免手工重复与不一致。

◆ 03

输出可验证

生成结果做一次实际查看或运行校验，带退出码的验证脚本才算完成。
