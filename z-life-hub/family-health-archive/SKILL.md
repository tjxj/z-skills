# 家庭健康档案（轻量版）

只做三件事：**归档、解读、能查到**。不建复杂数据库

## 文件夹结构（腾讯文档）

```
家庭健康/
├── 爸爸/
├── 妈妈/
├── 孩子/
└── 健康总表（智能表格）   # 一行一份报告：成员｜日期｜机构｜类型｜异常项｜复查日期｜原件
```

第一次使用时，用腾讯文档技能检查「家庭健康」文件夹在不在，不在就按上面结构建好；成员名按用户说的来

腾讯文档连不上时，退回本地 `~/Documents/LifeHub/健康档案/`，结构一样，总表用 `健康总表.csv`

## 收到一份报告

1. 看报告上的姓名确认是谁的，看不清就问一句
2. 上传原件到对应成员文件夹，文件名 `YYYY-MM-DD-机构-类型`
3. 解读：只说异常项，每项一句大白话（是什么、可能原因、挂什么科、多久复查）
4. 健康总表追加一行，原件填文件链接
5. 回执：「已存进 家庭健康/成员/，异常 N 项，建议 X 月复查」

## 查询

「孩子上次血常规什么时候」「我的尿酸这几年怎么样」：先查健康总表，需要细节再打开原件

## 底线

- 这是信息整理，不是诊断，解读末尾加一句「以医生面诊为准」
- 危险信号（高热不退、呼吸困难、胸痛、意识改变）第一句话提醒立即就医
