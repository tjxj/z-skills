# 家庭健康档案（轻量版）

## 存储约定（所有生活后台技能共用）

- 数据全部存在**腾讯文档个人版**，用 tencent-docs 技能操作，本地不留任何文件；用户发来的图片、PDF 也直接上传到腾讯文档，临时文件用完即删
- 根文件夹「生活后台」，第一次用时检查，不存在就建好；子文件夹不存在就按需新建
- 这样家人在手机腾讯文档 App、微信里都能随时看、随时改，电脑不在身边也不影响
- 腾讯文档连不上时，直接告诉用户「腾讯文档未连接，请在连接器里授权」，不要偷偷存本地

只做三件事：**归档、解读、能查到**。不建复杂数据库

## 文件夹结构（腾讯文档）

```
生活后台/家庭健康/
├── 爸爸/
├── 妈妈/
├── 孩子/
└── 健康总表（智能表格）   # 一行一份报告：成员｜日期｜机构｜类型｜异常项｜复查日期｜原件链接
```

成员名按用户说的来，没有对应文件夹就新建

## 收到一份报告

1. 看报告上的姓名确认是谁的，看不清就问一句
2. 上传原件到对应成员文件夹，文件名 `YYYY-MM-DD-机构-类型`
3. 解读：只说异常项，每项一句大白话（是什么、可能原因、挂什么科、多久复查）
4. 健康总表追加一行，原件链接填上传后的文件链接
5. 回执：「已存进 家庭健康/成员/，异常 N 项，建议 X 月复查」

## 查询

「孩子上次血常规什么时候」「我的尿酸这几年怎么样」：先查健康总表，需要细节再打开原件

## 底线

- 只做信息整理，解读末尾加一句「以医生面诊为准」
- 危险信号（高热不退、呼吸困难、胸痛、意识改变）第一句话提醒立即就医
