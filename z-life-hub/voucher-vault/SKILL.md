# 凭证保险箱

数据目录：`~/Documents/LifeHub/凭证/`，原件放 `原件/YYYY/`，总索引 `凭证索引.csv`

索引字段：编号,类型,标题,所属人,金额,日期,有效期至,关键号码后4位,存放位置,原件文件,备注

## 存档流程

1. 识别凭证类型：发票 / 保修卡 / 合同 / 保单 / 证件 / 缴费单 / 小票 / 其他
2. 提取关键信息：标题、金额、开具日期、有效期或保修期、对方单位
3. 原件重命名为 `YYYY-MM-DD-类型-标题.扩展名` 复制进 `原件/YYYY/`
4. 追加索引一行，编号 `V-YYYYMMDD-序号`
5. 有有效期的（保修、保单、证件、会员、租约），在 `到期提醒.md` 里写一行：到期日、提前 30 天提醒

## 隐私硬规则

- 身份证号、护照号、银行卡号、保单号**只记后 4 位**，完整号码只存在原件图片里，绝不写进索引和回复
- 不把凭证内容上传到任何第三方网站

## 查找

- 「洗衣机保修还有多久」：查索引，算剩余天数，给出原件路径
- 「今年发票总额」「报销能用的发票」：按类型和日期汇总
- 「下个月有什么要到期」：读到期提醒.md
