# 凭证保险箱

## 存储约定（所有生活后台技能共用）

- 数据全部存在**腾讯文档个人版**，用 tencent-docs 技能操作，本地不留任何文件；用户发来的图片、PDF 也直接上传到腾讯文档，临时文件用完即删
- 根文件夹「生活后台」，第一次用时检查，不存在就建好；子文件夹不存在就按需新建
- 这样家人在手机腾讯文档 App、微信里都能随时看、随时改，电脑不在身边也不影响
- 腾讯文档连不上时，直接告诉用户「腾讯文档未连接，请在连接器里授权」，不要偷偷存本地

位置：腾讯文档「生活后台/凭证/」，原件放 `原件/YYYY/`，总索引是智能表格「凭证索引」

索引字段：编号、类型、标题、所属人、金额、日期、有效期至、提醒日期、关键号码后4位、原件链接、备注

## 存档流程

1. 识别凭证类型：发票 / 保修卡 / 合同 / 保单 / 证件 / 缴费单 / 小票 / 其他
2. 提取关键信息：标题、金额、开具日期、有效期或保修期、对方单位
3. 原件命名为 `YYYY-MM-DD-类型-标题` 上传到 `原件/YYYY/`
4. 凭证索引追加一行，编号 `V-YYYYMMDD-序号`
5. 有有效期的（保修、保单、证件、会员、租约），提醒日期填到期前 30 天
6. 回执：类型、标题、有效期至、还剩多少天、原件链接

## 隐私硬规则

- 身份证号、护照号、银行卡号、保单号**只记后 4 位**，完整号码只存在原件图片里，绝不写进索引和回复

## 查找

- 「洗衣机保修还有多久」：查索引，算剩余天数，给出原件链接
- 「今年发票总额」「报销能用的发票」：按类型和日期汇总
- 「下个月有什么要到期」：按提醒日期筛选索引
