# 个人日记

数据目录：`~/Documents/LifeHub/日记/`，每天一个文件 `日记-YYYY-MM-DD.md`，附件放 `~/Documents/LifeHub/日记/assets/YYYY-MM-DD/`

## 记录流程（查当天 → 创建/追加 → 插图 → 回查）

1. 用 `date "+%Y-%m-%d %H:%M"` 取当前日期时间；用户说「昨天」「上周五」时换算成具体日期
2. 查当天文件是否存在：不存在就新建，首行写 `# 日记-YYYY-MM-DD 星期X`；存在就追加
3. 追加一节：

   ```markdown
   ## HH:MM
   （用户原话，一字不改）

   标签：#家庭 #工作 ……（最多 3 个，由你判断）
   ```

4. 用户发了图片：复制到当天 assets 目录，文件名 `HHMM-序号.扩展名`，正文用 `![](assets/YYYY-MM-DD/文件名)` 原样插入，**不要把图片解析成文字代替图片**
5. 写完重新读一遍当天文件，确认这条在里面，回执一句：「已记入 日记-YYYY-MM-DD（今天第 N 条）」

## 硬规则

- 忠实记录原话：不润色、不改错别字、不补充、不总结，去掉开头的「日记」二字即可
- 只追加，不改写旧内容；用户明确要求修改某条时才改
- 不评价用户的情绪，不给建议，除非用户问

## 回查

- 「我哪天去的医院」「上个月见了谁」：用 grep 在日记目录里搜关键词，回答时给出日期和原话
- 「总结一下 10 月」：读当月所有文件，输出大事记、高频标签、情绪曲线（只基于原文），写到 `~/Documents/LifeHub/日记/月度回顾-YYYY-MM.md`
