# 中文长文排版测试

排版工具真正难的地方，是让中文、英文、代码、表格和引用出现在同一份文档里时，依然保持稳定

## 三种风格

- 学术朴素风：重视清晰、引用与检索
- 文楷书籍风：重视长时间阅读的舒适度
- 现代报告风：重视层级、重点和展示效果

> 好排版不会抢内容的戏，它会让读者更愿意继续读下去

## 混合内容

从 Markdown 到 PDF 的流程很短：Markdown → Pandoc → XeLaTeX → PDF

| 项目 | 作用 |
|---|---|
| Pandoc | 读取 Markdown |
| XeLaTeX | 处理中文字体与页面布局 |
| 模板 | 决定文档气质 |

下面是一段命令行示例

```shell
bash scripts/build.sh -i article.md -o dist/article --style all
```

## 验收

最终文件需要能打开、有目录、中文不乱码，页眉页脚和章节标题也要完整
