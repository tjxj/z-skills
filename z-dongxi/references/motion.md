# 动作语法

每个动作都要有含义，不能为了动而动。一张图最多用 2~3 种动作。

| 动作 | 画面 | 表达的意思 |
|---|---|---|
| 行 | 小圆点或小标签沿线移动 | 数据 / 请求 / 物件从这里到那里 |
| 亮 | 卡片外框高亮 | 此刻正在处理这一步 |
| 绘 | 线条从起点画到终点 | 关系建立、消息发出 |
| 现 | 元素淡入 | 新信息出现 |
| 长 | 柱子、进度条生长 | 数量累积、时间流逝 |
| 滤 | 粒子掉出漏斗 | 被筛掉、被拦截 |
| 扩 | 圆环向外扩散 | 传播、影响范围变大 |
| 转 | 沿圆环绕行 | 循环、迭代 |
| 换 | 数字或文字离散切换 | 计数器、轮次、状态 |

## 时间规则

1. **一个周期讲完一遍故事**：所有动画共用周期 T，按 keyTimes 排队出场，不依赖事件触发（公众号不支持 begin="x.end"）
2. **结尾停留 2.6 秒**：故事讲完后留时间给人看，然后整体淡出，重新开始
3. **静态即终态**：不播放动画时（截图、PNG、不支持动画的阅读器），看到的就是完整的最终画面
4. **周期控制在 6~18 秒**：太短看不清，太长没人等

## 公众号兼容

可用：`<animate>`、`<animateMotion path="...">`、`<animateTransform>`、`<set>`
不可用：`id`、`<defs>`、`url(#)`、`<mpath href>`、`<style>`、`<script>`、CSS 动画、foreignObject
其他：SVG 必须单行（没有换行），文本里不能有全角句号
