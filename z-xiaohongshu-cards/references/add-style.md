# 沉淀新风格

每种风格是 `styles/<id>/` 下的一个目录：

```text
styles/<id>/
  template.html   可渲染的模板，风格的唯一来源
  STYLE.md        气质、适用内容、色板、字体、招牌元素、注意事项、来源
  preview.jpg     模板渲染总览
  samples/        原作样图，3–4 张，720×960 JPG
```

## 步骤

1. **取名**：`id` 用英文短横线，中文名四个字左右，要能让人想起画面，例如「黄便签手写」。
2. **做模板**：从作品的 `cards.html` 复制，删掉 `@font-face` 里的本机路径，图片换成 `.ph` 占位块。至少保留封面、内容、结尾三类页面。
3. **视频来源**：去掉时间轴和入场动画，把场景摊成静态 `.card`，保留配色、字体、版式和底部字幕带。源码找不到时，按成片截帧重建，再并排核对。
4. **放样图**：挑最能代表风格的 3–4 张原作，缩到 720×960，JPG 质量 80。视频截取画面稳定的帧。
5. **写 STYLE.md**：照现有风格的小节写，色板写具体色值。
6. **更新索引**：`SKILL.md` 的风格表、`README.md` 的风格表、`docs/styles-grid.jpg`。
7. **验收**：

   ```bash
   node scripts/check_all.cjs --write-preview
   ```

   再把模板渲染图和原作并排看一遍，配色、字重、版式对得上才算复现。

## 授权

公开仓库只放自己写的模板和自己的作品样图。第三方模板的代码不要复制进来，需要同类视觉时按色板和版式重写。
