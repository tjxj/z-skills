# 小红书 3:4 风格库

输入文章或要点，输出一组 1080×1440 PNG。每种风格都是一份能直接渲染的 HTML 模板。

## 风格

| id | 名称 | 适合 |
|---|---|---|
| `warm-paper` | 暖纸蓝橙 | 产品上手、App 教程、功能清单、对比选型 |
| `legal-pad` | 黄便签手写 | 教程、方法论、作品展示、学术与工具测评 |
| `rice-seal` | 宣纸朱印 | 诗词、历史、读书、人文项目 |
| `field-manual` | 现场手册 | 架构解释、SOP、决策清单、方法论 |

选定后读 `styles/<id>/STYLE.md`，看 `samples/` 里的原作，再动手。用户点名时直接用；没点名时按内容匹配，并避开上一组用过的风格。

## 流程

1. **拆页**：默认 6–9 页。封面一句钩子，内容页一页一个观点，结尾页给结论或行动。
2. **建目录**：新建工作目录，把 `styles/<id>/template.html` 复制成 `cards.html`，素材放进 `assets/`。
3. **填内容**：每页一个 `<section class="card" data-name="英文短名">`，沿用模板里的类名和色板。页面不够就复制同类页。`.ph` 占位块全部换成真实图片，正式稿不留占位块。
4. **渲染**：

   ```bash
   node <skill目录>/scripts/render.cjs cards.html --out output --sheet output/sheet.jpg
   ```

5. **看图**：打开总览图逐页看，处理遮挡、孤行、截图裁切。脚本只查尺寸和越界，视觉问题靠人眼。
6. **交付**：给 `output/` 里的 PNG。用户要发布文案时，再写一段简短正文。

## 版面规则

- 画布固定 1080×1440，导出 PNG。
- 中文默认思源宋体 VF。`SourceHanSerifSC-VF.ttf` 放在系统字体目录，或用环境变量 `XHS_SERIF_FONT` 指定路径。
- 手机上正文不小于 24px，标题不小于 76px。
- 模板里出血或裁切的装饰元素加 `data-bleed`，渲染检查会跳过它们。
- 所有图片用相对路径，HTML 里不写本机绝对路径。

## 沉淀新风格

用户说「沉淀这个风格」，或做出了风格库之外的设计时，按 `references/add-style.md` 执行。风格必须带模板、说明和样图，并通过 `scripts/check_all.cjs`。
