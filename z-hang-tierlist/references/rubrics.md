# 评分维度和锚点

## 怎么用

1. 按主题挑下面一套（或照通用骨架自己搭），3-5 个维度，权重加起来 100
2. 每个维度写 `rubric`：10 / 7 / 4 / 1 分各是什么样，尽量绑数字
3. 打分时一次只看一个维度，所有候选放在一起排，再按锚点给分，可以给 0.5 分

## 分数怎么校准

分档线：≥ 9.0 夯，≥ 8.0 顶级，≥ 7.0 人上人，≥ 5.5 NPC，< 5.5 拉完了。锚点按这个设计：

| 分 | 意思 |
|---|---|
| 10 | 这个维度的天花板，全场第一或并列第一 |
| 8-9 | 第一梯队，明显强于同行 |
| 7 | 好于平均，有亮点 |
| 5-6 | 平均水平，没毛病也没记忆点 |
| 4 | 低于平均，有明显短板 |
| 1-3 | 有硬伤、有实锤问题，或垫底 |

推论：

- 进「夯」要几乎每个维度都在第一梯队（加权 ≥ 9.0），一般只有 1-3 个
- 全面平庸约等于 5.5，正好卡在 NPC 和拉完了之间，所以「拉完了」至少要有一个维度有硬伤
- 分数全挤在 6-8 之间，说明量表没用满：回头看第一名该不该给 10，最后一名该不该给 3

候选池整体都很强（比如只收各家旗舰）时，可以把 `cuts` 整体下调（如 `[8.6, 7.6, 6.6, 5.2]`），在 `scope` 里写明，一张榜只用一套分档线。

## 通用骨架

## 公众人物（慎用）

能不做就不做。必须做时：只评公开作品和业绩，不评人品和私生活；维度用作品质量、商业成绩、专业评价、影响力；负面只写有判决或官方通报的事实。
