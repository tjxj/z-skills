# Poetry Book：让资料自己长成一本书

如果一个技能只是把文字塞进模板，那么它产出的不是书，只是一份长文档。**Poetry Book 想解决的问题，是把分散、庞杂、格式不一的资料，变成一本结构完整、出处可查、版式统一，而且经过完整验证的书。**

它抽象出来的，不只是一个 PDF 模板，而是一条从资料到成品的出版流水线。

## 一、这个技能做什么

使用者只需要按照约定提供资料，Poetry Book 就能完成下载登记、文本抽取、去重、编年、批注、排版和验证，最后输出一本可阅读的 PDF 图书。

它的输入和输出非常清楚：

| 输入 | 输出 |
|---|---|
| 古籍文本、开放 JSON 数据、网页资料 | 编年排版的 PDF 图书 |
| 年谱、卷次与年代映射 | 可检索的作品数据库 |
| 名篇题解、字词注和评语 | 作品与页码对应表 |
| Markdown 技术文章与配图 | 技术图文专题或课程讲义 |
| 版式、字体和授权信息 | 来源与版本清单 |
| 校验规则 | PDF 验收报告和预览图 |

使用者提供的是“材料”，这个技能负责把材料组织成“书”。

## 二、资料是怎样变成书的

### 1. 先保存证据，再处理内容

Poetry Book 不会一上来就改写文本。它首先登记原始资料来自哪里、版本是什么、提交号是多少、文件是否完整，并保存 SHA-256 校验值。

这意味着书中的每一项内容，都可以回溯到原始文件、卷次、页签、网页、JSON 条目或 Markdown 行号。资料不是从网上抓来后就不再可追溯的一团文字。

### 2. 建立统一的作品数据库

随后，技能把不同来源的文本转换成统一的作品记录，包括：

- 题名、体裁和正文；
- 原始文本、规范化文本和展示文本；
- 来源文件、卷页和条目 ID；
- 重复与异文信息；
- 系年、年代区间和判断依据；
- 题解、批注和人生阶段。

同一个题目可能被不同古籍收录，同一词牌也有几十首作品。Poetry Book 使用“题名＋首句＋正文”共同识别，避免把不同作品误并，也避免组诗只保留第一首。

### 3. 用作品组织时间，而不是简单按标题排序

编年是这个技能的核心，而不只是附加字段。

能够确定年月日的，按确切时间排序；只能确定卷次或人生阶段的，按区间排列；没有可靠依据的，明确标为“系年未详”。它不会为了让目录看起来整齐而虚构年份。

随后，作品被放进作者的人生经历中：出蜀、入仕、外任、贬谪、再起、北归。读者看到的不只是诗词列表，而是作品与人物命运相互印证的长卷。

### 4. 把编辑内容放在独立层

名篇题解、字词注和朱批不会混进原文。它们单独保存，在生成书稿时叠加进去。

这样一来，古籍原文不需要为了迁就注释而改写，编辑也可以单独修订某一篇批注，再重新生成整本书。

技术文章采用另一层结构：标题、粗体、列表、链接、图片、代码、表格和引用先转换为有原稿行号的内容块，再进入同一个排版与验收引擎。文章不会被强行加上诗词的系年说明。

## 三、它输出怎样的阅读风格

成品采用 **简体中文、横排易读版**。古书气质主要体现在封面和章首，而不是牺牲阅读效率。

目前已经实现六套可实际构建的主题：

| 主题 ID | 名称 | 视觉方向 |
|---|---|---|
| `song-mist` | 烟雨留白 | 米白、淡墨、远山、江面与朱印；默认主题 |
| `celadon` | 青瓷天青 | 青灰纸色、天青层山，温润清透 |
| `ink-zen` | 墨禅寂照 | 灰白、墨山、圆相与墨评 |
| `cinnabar-seal` | 朱砂印谱 | 米纸、朱砂和鉴藏印章 |
| `moon-river` | 月夜赤壁 | 蓝灰、明月、江水与夜航 |
| `bamboo` | 竹影清风 | 淡青绿、疏竹与叶影 |

内页采用较大字号、宽松行距和清晰的批注区块，并加入目录、书签和索引。它不是“古风滤镜”，而是一种适合实际阅读的编辑设计：封面有宋代审美，正文为现代横排，年代、术语、图片和出处都有明确体例。

## 四、这个技能怎样避免“看起来完成了”

Poetry Book 不以“PDF 能打开”作为完成标准，而是要求整条生产线通过验证。

它会检查：

- 来源文件是否完整、版本是否一致；
- 作品是否有空正文、重复 ID 或异常控制符；
- 组诗是否完整，是否误收他人唱和；
- 年代区间、排序和名篇文本是否吻合；
- 批注是否挂接到正确作品；
- 所有作品是否真正出现在 PDF 中；
- 字体是否嵌入，生僻字是否缺失；
- 是否存在文字越界、异常空白页和排版溢出；
- 技术文章的图片数量、图片比例、链接和 Markdown 残留是否正确；
- 全书能否从干净目录重新生成。

**能编译，不等于没有缺陷；通过检查，才允许交付。**

## 五、一次真实验证：苏轼编年诗传

这个技能已经在《用诗词读懂苏轼——一蓑烟雨任平生》中完整跑通。

本次实际成品具有如下规模：

- 下载 11 个古籍与开放资料仓库，以及 18 个维基文库页面；
- 收录诗 2824 条、词 362 条，另收 16 篇赋、记、传、铭等作品；
- 合计 3202 条作品，82 篇名篇精注；
- 2651 条作品具有古籍互见记录；
- 2394 条具有系年或区间依据，其余明确标为未系年；
- 最终 PDF 为 1448 页，采用宋代审美封面和简体横排正文。

首版执行了 13 项数据测试、73 项来源检查和 19 项 PDF 检查，共 105 项。加入主题资源和产物防覆盖测试后，当前默认全书为 **16 项项目测试、73 项来源检查和 19 项 PDF 检查，共 108 项，全部通过**。两组数字对应不同版本，不混作同一次统计。

六套主题还分别生成了 39 页、21 条代表作品的样张；完整的青瓷版同样为 1448 页、3202 条作品。样张与完整书的 PDF、校验报告、作品页映射和预览目录相互独立，避免互相覆盖。

## 六、能力扩展：老章 AI 技术专题

为了验证它不只适用于诗词，我把“AI学习的老章”的 DeepInfer 技术文章制作成了完整专题样张：

**《打平 DeepInfer——SGLang 与 vLLM 联袂反攻》**

这本小册采用青瓷天青主题和“老章”印章，封面标明“AI学习的老章 著”。实际结果为：

- 15 页，保留开篇和四个主章节，共 5 个内容区段；
- 下载并嵌入 7 张原文图片，逐张记录 URL、尺寸和 SHA-256；
- 保留原稿标题、粗体、列表和原文链接；
- 按原稿行号记录章节来源，不显示诗词模式的系年依据；
- 通过 22 项 PDF 检查，包括图片数量、宽高比、链接、关键语句和 Markdown 残留；
- 缺字、排版溢出、文字越界和异常空白页均为零；
- 从安装后的 Skill 离线重建，仍是 15 页、7 张图片、22 项检查全部通过。

另用一份含长代码、简单表格、引用和链接的技术夹具生成了 5 页 PDF，20 项检查通过。这说明技术模式不是只对当前这篇文章有效。

原稿没有修改。文章中的性能数据、产业判断和未来预测仍属于原文内容，本次工作是结构解析与排版，不冒充独立技术事实核验。

## 七、怎样复用这个技能

技能安装位置为 `~/.agents/skills/poetry-book/`。诗词或已经结构化的资料使用：

```bash
python3 "$HOME/.agents/skills/poetry-book/scripts/render_book.py" \
  --input "/absolute/path/book.json" \
  --theme "song-mist" \
  --output "/absolute/path/new-output-directory"
```

普通 Markdown 技术文章使用：

```bash
python3 "$HOME/.agents/skills/poetry-book/scripts/render_article.py" \
  --input "/absolute/path/article.md" \
  --theme "celadon" \
  --title "文章主标题" \
  --subtitle "文章副标题" \
  --author "作者或栏目名" \
  --seal "印章文字" \
  --output "/absolute/path/new-output-directory"
```

网络图片只接受 HTTPS，并保存尺寸和校验值；使用 `--offline` 时只复用已有图片。技术模式支持常见标题、粗体、行内代码、链接、列表、图片、代码块、简单表格和引用。复杂 HTML、嵌套列表、数学公式和复杂表格不是当前已验证的支持范围。

在苏轼项目中，还可以执行：

```bash
make themes                 # 构建六套风格样张
make theme THEME=celadon   # 构建完整青瓷版
make article-sample        # 离线重建老章技术专题
make article-test          # 验证技术文章与技术夹具
make clean test            # 默认全书及通用能力回归
```

## 结语

Poetry Book 真正可复用的，不是某一张封面，也不是某一本苏轼诗传，而是一套机制：

**让资料有出处，让内容有结构，让批注有层次，让图片不失真，让排版有风格，让成品经得起重新生成和逐项检查。**

这就是它作为一个技能的价值：输入大量资料，输出的不只是 PDF，而是一本可信、可读、可复核的书。诗词可以，技术文章也可以。
