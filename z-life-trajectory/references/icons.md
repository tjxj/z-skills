# 图标清单

50 个会动的小图标，用在 `station`、`card`、`counter`、`exchange`、`icons`、`compare` 的 `icon` 字段，或者在插件里用 `c.icon(名字, cx, cy, scale)`。

看全部图标的样子（浏览器打开）：

```bash
python3 scripts/lifeline.py icons icons.svg --theme terra
```

| 名字 | 适合表达（动效） |
|---|---|
| `book` | 读书、语言、写作（书页来回翻） |
| `cap` | 毕业、学位（流苏摆动） |
| `school` | 入学、学校（旗子飘） |
| `computer` | 电脑、编程启蒙（绿屏打字） |
| `workstation` | 图形、3D、工作站（屏里立方体旋转） |
| `cube` | 3D、建模、产品（线框立方体旋转） |
| `code` | 写代码、软件（终端打字） |
| `chip` | 芯片、硬件（核心阵列闪烁） |
| `plane` | 出国、远行（飞机沿航线飞） |
| `ship` | 远渡、移民（船在浪上摇） |
| `car` | 汽车、出行（车轮转、路在走） |
| `globe` | 全球化、国际（地球转、卫星绕） |
| `pin` | 地点、搬迁（定位针弹跳） |
| `house` | 家、童年、车库（窗灯明灭、烟囱冒烟） |
| `building` | 公司、总部（窗户逐个亮起） |
| `medal` | 奖章、勋章（摆动） |
| `trophy` | 冠军、奖杯（闪光） |
| `star` | 荣誉、明星（旋转闪光） |
| `crown` | 登顶、第一（浮动闪光） |
| `money` | 融资、财富（硬币堆高、旋转） |
| `chart` | 增长、市值（折线上扬） |
| `chart_down` | 下跌、危机（折线下坠） |
| `mic` | 演讲、发布会（声波） |
| `pen` | 签约、写作（笔写出签名） |
| `brush` | 艺术、设计（调色盘、笔触） |
| `camera` | 拍摄、媒体（闪光） |
| `film` | 电影、影视（胶片转） |
| `music` | 音乐（音符跳） |
| `chat` | 对话、AI 聊天（打字气泡） |
| `phone` | 手机、社交（消息弹出） |
| `letter` | 信件、公开信（信纸滑出） |
| `newspaper` | 新闻、报道（标题被划重点） |
| `calendar` | 日期、日程（日期框跳动） |
| `clock` | 时间、倒计时（指针转） |
| `people` | 团队、合伙人（中心人物波纹） |
| `heart` | 婚姻、爱情、公益（心跳） |
| `ecg` | 健康、疾病（心电图） |
| `candle` | 纪念、离世（烛光摇曳） |
| `cake` | 生日、周年（烛火跳） |
| `coffee` | 咖啡馆、打工、深夜（热气升起） |
| `dumbbell` | 健身、体育（杠铃上下） |
| `ball` | 运动、比赛（球弹跳） |
| `briefcase` | 入职、跳槽（公文包） |
| `flag` | 里程碑、登顶（旗帜飘） |
| `rocket` | 发射、创业起飞（火焰） |
| `bulb` | 灵感、发明（灯泡发光） |
| `gear` | 工程、制造（齿轮咬合） |
| `flask` | 科研、实验（烧瓶冒泡） |
| `gavel` | 诉讼、判决（法槌落下） |

没有合适的就挑意思最接近的，或者在插件里自己画（见 `custom-blocks.md`）。不引用外部图片。
