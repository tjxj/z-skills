# 分屏和版面

## 整体结构

| 部分 | 屏数 | 内容 |
|---|---|---|
| 封面 | 1 | 新闻条（由头）、大数字、人名、生卒年、走过的地方、蛇形人生线路图 |
| 开头 | 2~3 | 出生、家庭、童年、迁徙。节奏快，一屏可以装 3~4 站 |
| 成长 | 2~4 | 求学、第一份工作、遇到关键的人 |
| 主线 | 5~8 | 事业起步、濒临失败、转折、高峰。插画和图表集中在这里 |
| 高潮 | 1 | 全片唯一的深色屏，放最大的那个数字 |
| 收尾 | 1~2 | 由头事件、终点站、人生进度条 |

总数控制在封面 + 12~18 屏。少于 10 屏显得单薄，多于 20 屏手机上滑不完。

一屏讲一个时期，按时间顺序往下走。同一个时期的事太多，就拆成两屏，或者用 `compact` 把次要的事压成一列。

## 封面

- `news`：由头新闻，一句话，写清楚谁宣布了什么。日期用公告日
- `kicker` + `big` + `big_unit`：最能代表这个人的一个数字，比如「执掌英伟达 33 年」「连任 4 届」「拿了 23 个大满贯」
- `route`：一生住过、待过的城市，3~6 个，用 → 连接
- `stops`：线路图上的站，10~15 个，站名 5 字左右。从后面各屏的标题事件里挑，`major` 留给 3~4 个最重要的转折
- `hint`：一句提示，比如「往下，逐站细看」

## 每一屏

| 位置 | 字段 | 写法 |
|---|---|---|
| 左上 | `era` | 时期，`1985 — 1992`，可以加地点 `1973 — 1975 · 肯塔基` |
| 大标题 | `title` | 这段时间发生了什么，12 字内。写动作和结果：「被三家公司拒绝」好过「求职之路」 |
| 副标题 | `sub` | 一个具体细节：时间、地点、人数、金额，24 字内 |
| 正文 | `blocks` | 3~5 个块，至少一个插画或图表 |

内容区：有 `sub` 时从屏顶往下 236px 开始，到 960px 结束，可用约 724px；只有 `title` 时可用约 760px。正文横向从 x=118 到 x=702，左侧 x=78 是贯穿全片的主线。

### 常用块的高度

排版前心里有个数，省得反复改：

| 块 | 高度（px） |
|---|---|
| `station` | 只有标题 70，一行说明 108，两行说明 141 |
| `compact` | 一条约 30~70 |
| `card` | 190~290 |
| `journey` | 108 |
| `lifebar` | 112 |
| `quote` | 约 130 |
| `bigstat` | 约 140 |
| `counter` | 140 |
| `exchange` / `team` / `hbars` | 200~216 |
| `ring` | 228 |
| `plaque` | 240 |
| `bars` | 自己定，示例里 546 |

块和块之间的间距自动分：内容少就拉开（每处最多多出 46px），内容多就压缩（每处最少 14px）。压到 14px 还放不下报 `CROWDED`；内容不到六成高报 `SPARSE`。

一屏比较舒服的组合：3 个 `station` + 1 个插画块；或者 1 个 `station` + 1 个大图表（`bars`、`ring`）+ 1 个 `quote`。

## 按事实选块

| 事实 | 块 |
|---|---|
| 出生、搬家、出国 | `station` + `journey`（plane / ship / car / train） |
| 入学、毕业、拿学位 | `station` 配 `cap`、`school` 图标；几件小事连着就用 `compact` |
| 打工、第一份工作 | `card`（左边图标） |
| 两个人互相学到东西 | `exchange` |
| 日复一日的坚持 | `counter` |
| 创业、合伙人 | `team`，启动资金用 `tokens` 叠在旁边 |
| 产品、作品、发明 | `card`、`icons`，或者写定制插画块 |
| 濒临失败、只剩几个月 | `ring`（耗尽后被救回） |
| 同行一个个倒下 | `dots`（幸存者点阵） |
| 两条路线之争 | `compare` |
| 市值、股价、用户数随时间涨 | `bars` |
| 营收、身家、排名比大小 | `hbars` |
| 一个惊人的数字 | `bigstat`，放深色屏效果最好 |
| 本人说过的话 | `quote` |
| 获奖、纪念、命名 | `plaque` |
| 收尾 | `terminus` + `lifebar` |

不要连着两屏只有站点。每 2~3 屏安排一个会动的大插画，读者往下滑才有期待。

## 节奏

- 开头 3 屏要快：出生到成年用 `compact` 和小插画带过，别在童年停太久
- 中段把插画和图表摊开，避免两个大图表挤在同一屏
- 深色屏放在全片 70%~85% 的位置，最大的数字留给它。全片只用一次
- 最后一屏：由头事件写成 `terminus`，下面接 `lifebar` 总结一生，`sources` 显示在底部

## 主题

| 主题 | 主色 | 适合 |
|---|---|---|
| `terra` | 陶土橙，辅色青绿 | 默认。企业家、创作者，温暖的叙事 |
| `indigo` | 靛蓝，辅色赭石 | 科技、金融、工程师 |
| `jade` | 玉绿，辅色陶土 | 科学家、作家、艺术家 |
| `crimson` | 绯红，辅色靛蓝 | 运动员、政治人物、起伏大的人生 |

主题色只在重点处出现：大站圆点、大数字、引语最后一行、图表里的主角。其他文字保持墨色和灰色。要微调就在 spec 里写 `colors` 覆盖。

## 文案

- 数字写具体：「600 美元」「72 个核心」「180 天」，少用「巨额」「大量」
- 站点标题 18 字内，写这个节点发生了什么；说明每行 26 字内，最多两行
- 少写「伟大」「传奇」这类评价，让数字和细节说话
- 标题不用夸张词（震惊、封神、炸裂、逆天）
- 地名写到城市一级，用通行的中文译名
- 同一个人名、公司名全片写法统一
